# airbnb-clone-project
A simple clone of airbnb website built as part of my ALX project.

This project is a clone of the Airbnb platform, designed to replcate its main features suchas property listings, search, booking, and user authentication. It's part of the ALX software engineering curriculum to demonstrate front-end and back-end web development skills.



## 🎯 Project Goals
- Understand how full-stack web applications work.  
- Practice building front-end interfaces with HTML, CSS, and JavaScript.   
- Learn version control and project collaboration with Git and GitHub.

## 🧰 Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Version Control:** Git & GitHub
